# PinSpective

Camera golf rangefinder prototype. See the pin. Know the distance.

Open the GitHub Pages link on your phone, tap Start, and allow camera, motion and location.

## Native iOS prototype (camera distance accuracy)

`ios/` contains a native Swift/SwiftUI app for the iPhone 16 Pro Max 5× telephoto that tests
whether the camera alone can measure flagstick distance (no GPS, maps or internet). See
`ios/README.md` for install and test steps and `docs/FEASIBILITY.md` for the physics, error budget
and method comparison.
